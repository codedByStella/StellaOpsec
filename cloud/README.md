# Cloud Scripts

This directory contains two personal PowerShell projects that query selected Azure and Google Cloud settings.

- [Azure](azure/README.md)
- [Google Cloud](gcp/README.md)

The scripts use the relevant vendor command-line tools to retrieve configuration information. Their coverage is selective; they do not establish whether a tenant or project is secure, meet a compliance requirement, or have no exposure.

The provider-specific notes record the areas explored, dependencies, and limitations of each script.
