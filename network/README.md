# Network Scripts

This directory contains personal experiments involving network and web configuration information.

- [NetworkSweep](NetworkSweep.README.md) — host reachability, selected port checks, DNS zone-transfer behavior, and TLS observations.
- [WebAssessment](WebAssessment.README.md) — HTTP response details, selected security headers, cookie attributes, and TLS-related information.

NetworkSweep was written for PowerShell 7.0 or later. WebAssessment was written for PowerShell 5.1 or later.

Network behavior depends on routing, firewalls, proxies, DNS, rate limits, and the service being queried. These scripts provide limited observations; they do not determine whether a system or website is secure or vulnerable.
