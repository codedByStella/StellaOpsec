# Sensitive Information

StellaOpsec is a personal project, not a security product or a vulnerability-reporting service.

Some script output can include usernames, hostnames, internal addresses, service details, cloud resource identifiers, configuration values, or other sensitive operational information. Do not post unredacted output, credentials, tokens, personal information, or private system details in public issues or discussions.

If you notice a problem in the scripts, you can describe it through the repository's normal GitHub contact options. Leave out secrets and sensitive data. There is no guaranteed response time, support commitment, or remediation service associated with this project.
